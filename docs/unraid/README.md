# Unraid template

`muxarr.xml` is the Community Applications template, `muxarr.png` the 256x256 icon. CA reads
them straight from this repo on master, so the URLs in the XML point here. `ca_profile.xml`
has to sit in the repo root, that's the only place CA looks.

Submit or re-scan at https://ca.unraid.net/submit. After that CA picks up changes by itself.

To try it on an Unraid box: Docker > Add Container, paste the raw `muxarr.xml` URL in the
Template field.
